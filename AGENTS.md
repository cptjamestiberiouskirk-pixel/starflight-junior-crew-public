# Starflight: Junior Crew project instructions

- Use the installed official Meshy CLI (`meshy.cmd`) for this project's Meshy work. This is the user's preferred connection method; use its saved browser login rather than setting up an API-key MCP connection unless the user requests a change.
- Reuse the global CLI installation. Check `meshy.cmd auth status --format json --no-update-check` before work that requires authentication. Do not submit a generation merely to test the connection.
- Keep generated assets and evidence in this project's asset/artifact directories. Preserve the ship's established hull shape and scale, original gameplay and equipment rules, mission progression, recorded voices, and save compatibility.
- Do not use Blender for future work. This user instruction supersedes the earlier Blender 5.2 preference.
- New visual/audio asset work must use only Meshy, Mirelo, Sonilo, ElevenLabs, or custom AI work.
- Use Meshy for image creation/editing and ElevenLabs for video creation. Use the installed Meshy CLI; verify access and obtain a fresh quote and spending approval before any new paid generation.
- Keep work local unless the user explicitly authorizes publishing.

- Keep music, sound effects, and voices muted during testing, as requested by the user. Use disposable-session settings; preserve production defaults and existing owner saves.

- Prefer Playwright for testing where it adds value. Preserve existing browser restrictions and use native or human checks where physical input or Windows settings are required.

## Animation realism
- All animations must look physically believable while preserving the game's established art style, ship hull, scale and installed configuration.
- Ship takeoff, approach, docking and undocking must use an angled three-quarter perspective with visible depth, rather than a flat top-down view or an unexplained straight vertical translation.
- Use coherent direction and thrust, gradual acceleration/deceleration, alignment with the original berth/clamps and a gentle supported landing. Preserve equipment, engine locations and door mechanics throughout; review actual rendered motion rather than treating a prompt as proof.
