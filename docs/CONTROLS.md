# Controls reference

Controls depend on the current view. Click back into the game after using a text
field. Focused controls/dialogs may consume keys. Visible controls and
disabled-state explanations take precedence over shortcuts.

| Context | Input | Action |
| --- | --- | --- |
| Normal play | P / Escape | Toggle pause; a focused dialog may handle Escape first |
| Menus | Mouse/touch; Tab, Shift+Tab, Enter | Select controls and navigate forms |
| Concourse | WASD / arrows | Walk |
| Concourse | Click destination/door | Walk toward or enter a station |
| Near concourse door | Enter / Space | Enter nearby station |
| Station room | Concourse button | Return to concourse |
| Flight | Navigation → Maneuver; WASD / arrows | Directional maneuvering |
| Small-screen flight | Visible steering pad | Hold a direction; release to stop issuing thrust |
| System/hyperspace | + / = and − | Zoom main flight view |
| Starmap | Visible zoom/view controls | Inspect chart; read its legend |
| Orbit | Leave Orbit | Return to system flight |
| Science | Scan planet, Analyze reading, tabs | Measure, interpret and inspect |
| Landing map | Click map / coordinate buttons | Select latitude/longitude |
| Landing map | INITIATE DESCENT BURN | Land when permitted |
| Supported cinematic | Enter / Space | Skip sequence |
| Rover | WASD / arrows; visible steering pad | Drive; override auto-drive/tracking |
| Rover | M | Open/close topographical map |
| Tactical map | Click destination | Set rover waypoint |
| Rover | V | Select drive mode |
| Rover | Q | Surface scan |
| Rover | L | Look nearby |
| Rover | C | Collect nearby eligible cargo, not open hold inventory |
| Rover | Hold readout | Open hold inventory |
| Rover | G | Start/stop mining; Mine button opens its console |
| Mining | Select deposit, Approach deposit, start/stop | Choose target, reach range and extract |
| Rover | R | Open/close weapon choices |
| Rover | F / Space | Fire selected surface weapon |
| Rover | Cargo → Record lifeform | Record eligible nearby life with tracking assist |
| Rover | Return to ship | Set return route when available |
| Near landed ship | B / Enter; Board Starship | Board within range |
| Ground view | Visible − / + / Reset view | Change surface camera zoom |
| Encounter | Tab / T | Cycle target |
| Encounter | WASD / arrows; digits 1–9 except 5 | Tactical movement; 1/3/7/9 are diagonals |
| Combat | Shield, arm/disarm and weapon buttons | Configure protection and fire available weapons |
| Pause → Mission | Save Mission / Save Slots | Save, manage slots and export/import |

Use labeled controls for docking, ascent, repairs, treatment and communications.
Typing a name should not steer the ship. Settings control audio, graphics,
shake and CRT. Developer shortcuts belong in [Development](DEVELOPMENT.md);
they are not needed to play and can mark a mission as a development save.

Crew guidance opens an optional hint based on the current location, equipment,
crew availability and received bulletins. Hide it with the same button.
In a star system, Navigation focus marks a planet and shows an edge pointer when
it is outside the view. It does not steer the ship; approach and use the existing
Orbit or Dock controls. These presentation choices reset when the game reloads.

Ship Configuration previews the next equipment class beside the current class,
including its capacity or damage, mass and purchase price. Selecting a preview
does not buy equipment. During recorded crew banter, the bridge shows the current
speaker's portrait and full subtitle above the searchable log.

The **Expedition clock** in the top HUD shows the existing stardate and hour.
On small screens it gets its own labeled row, including compact Science. Live
alien transmissions also show the same clock. This is in-game time: the existing
flight, pause and Starport time rules still apply. It is not a real-time stopwatch.
