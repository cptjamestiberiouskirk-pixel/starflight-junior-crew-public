# Choosing bridge officers

Every bridge role requires a different living crew member. In both Starport's
Crew Assignment room and the paused mission's Crew Assignments panel, each
dropdown shows every roster member's relevant value before their name:

| Role | Value shown |
| --- | --- |
| Captain | Total of all five skills, used by captain diplomacy |
| Science Officer | Science |
| Navigator | Navigation |
| Engineer | Engineering |
| Communications | Communications |
| Doctor | Medicine |

**(Recommended)** marks the conscious, living officer with the highest value
who is available for that role. An officer assigned to another role is unavailable;
vacate that role first to move them. Ties favor the current officer, then higher
vitality, then roster order. If nobody eligible is conscious, no recommendation
appears. This is advice for one role at a time, not an automatic allocation of the
whole crew.

Assigned and deceased officers retain their displayed skill values, with unavailable
options disabled and the reason included. Recommendations never assign anyone,
write a save, alter skills, or change recruitment, training or launch rules.
Existing saved assignments and crew identities remain intact.
